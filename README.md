# Queueing Game with Server Activation Policies

This repository contains the Python code for the paper:

**"Equilibrium and Learning Dynamics of Strategic Customers 
in Queueing Systems with Server Activation Policies"**  
Y. Sakuma and A. Nakamura,  
submitted to *Computers & Operations Research*.

## Contents
- `LDQBD_Nash_equilibrium.py`: Computes Nash equilibrium 
  threshold strategies for the MV, SV, ST, and NT models 
  using the level-dependent quasi-birth-and-death (LDQBD) 
  framework.
- `ABM_queue_server_activation_policy.py`: Agent-based 
  model (ABM) for simulating the learning dynamics of 
  boundedly rational customers toward Nash equilibrium.

## Requirements
- Python 3.x
- numpy
- scipy
- matplotlib

## Usage
Each script can be run directly in Google Colab 
or a local Python environment.
Parameters can be configured at the top of each script.
